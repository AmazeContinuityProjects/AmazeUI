# AmazeUI

The design library for AmazeCC

## Deprecated exports

`LoginForm` and `NavigationTabs` are deprecated and will be removed in the next
major version. They are app-specific copies that no AmazeCC app imports any
more, and they have drifted from the live versions in the AmazeCC repo. If you
use them, copy the component into your app or build it from AmazeUI's
primitives (`MobileBottomNav`, `SubTabStrip`, `AppLibrary`).
