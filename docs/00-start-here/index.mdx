AmazeUI is a TypeScript package of reusable React components, hooks, helpers, and a Tailwind CSS entrypoint. This handbook is written for a developer who knows HTML and is new to React, JSX, TypeScript, Tailwind, or npm library integration.

<Warning>This package is not a complete application. Components render UI and expose callbacks; your application remains responsible for routing, fetching, authorization, persistence, and business rules unless a component's source explicitly implements them.</Warning>

The package source is in `src/`. The root API is defined by `src/index.ts`. If a source file is not exported there, consumers cannot assume it is available from `@amazecontinuityprojects/amazeui`.
