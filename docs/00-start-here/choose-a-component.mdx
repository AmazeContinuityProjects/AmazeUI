---
title: Choose a component
description: Browse AmazeUI's public components by the interface task you want to build.
---

Start from the user task. A button triggers an action; an input collects a value; a dialog presents focused content. Prefer the smallest component that matches the task, then add the appropriate application state and accessible labels.

| Task                                              | Start with                                                                                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Action, link, text field, selection               | `Button`, `Link`, `Input`, `Textarea`, `Select`, `Checkbox`, `Switch`                                                                                   |
| Loading, error, empty data, or status             | `Skeleton`, `LoadingSpinner`, `LoadingScreen`, `ErrorDisplay`, `ErrorDiagnosticCard`, `EmptyState`, `Alert`, `Badge`, `StatusBadge`, `SyncNotification` |
| Page heading, section, breadcrumbs, sidebar, tabs | `PageHeader`, `SectionHeader`, `Breadcrumbs`, `Sidebar`, `Tabs`, `SubTabStrip`, `NavigationTabs`, `MobileBottomNav`                                     |
| Dialog, modal, popover, dropdown, command search  | `Dialog`, `Modal`, `Popover`, `DropdownMenu`, `Command`, `CommandPalette`                                                                               |
| Data rows, timetable, course list, timeline       | `DataTable`, `Table`, `TimetableGrid`, `CourseListTable`, `Timeline`                                                                                    |
| Progress and summary display                      | `Progress`, `ProgressBar`, `CircularProgress`, `InfoRow`, `IconBadge`                                                                                   |
| Theme and color choice                            | `ThemeProvider`, `ThemeSwitcher`, `useTheme`, `useColorPalette`, `ColorPalettePicker`                                                                   |

The [public export catalog](/04-reference/public-export-catalog) lists each root export and its source module. Read the component guide for prop types, required state, and integration needs. Source types in the current version are the final authority when a table differs from an installed version.
