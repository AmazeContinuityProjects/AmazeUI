## Button

`Button` is exported from `src/components/ui/button.tsx`. It accepts children, optional visual `variant` and `size`, an `onPress` callback from the React Native Web pressable type, a web `onClick` callback, `asChild`, `className`, `textClassName`, `type`, and forwarded pressable props.

| Prop                  | Accepted values / behavior                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- | --- | ------------------------------------------------- |
| `variant`             | `default`, `primary`, `destructive`, `danger`, `success`, `outline`, `secondary`, `ghost`, `link`; defaults to `default`. |
| `size`                | `default`, `sm`, `lg`, `icon`, `icon-sm`, `icon-lg`; defaults to `default`.                                               |
| `type`                | `button`, `submit`, `reset`; use the right value when inside a form.                                                      |
| `onPress` / `onClick` | The implementation uses `onPress                                                                                          |     | onClick`, so `onPress` wins if both are supplied. |
| `asChild`             | When true, clones its single valid child through the internal `Slot` helper and forwards class/callback props.            |
| `className`           | Merged after the variant classes; `cn` resolves conflicting Tailwind utilities.                                           |
| `textClassName`       | Applied to string or number children wrapped in the library `Text` primitive.                                             |

String and numeric children are wrapped in `Text`; element children are passed through. This affects styling and means custom child composition should be tested in the consuming app.

## Input, Textarea, and Select

These three exports come from `src/components/ui/input.tsx` and wrap native HTML elements. `Input` extends `React.InputHTMLAttributes<HTMLInputElement>` with optional `label` and `error`. `Textarea` extends the native textarea attributes with the same additions. `Select` extends native select attributes and requires `options: { value: string; label: string }[]`.

Each can receive `id`, `className`, and standard element props such as `value`, `onChange`, `name`, `required`, `disabled`, and `autoComplete`. If a `label` is supplied without an explicit `id`, its lowercase text with spaces changed to hyphens is used as the input id. For labels with punctuation or duplicate names, pass a unique `id` explicitly. `error` displays a message and changes input border styling, but does not itself validate or link an accessible description.

```tsx
<Input id="email" label="Email" type="email" value={email} onChange={handleEmailChange} />
<Select label="Year" options={[{ value: "2026", label: "2026" }]} value={year} onChange={handleYearChange} />
```

## Other controls

- `Checkbox` wraps Radix Checkbox Root and forwards its checkbox primitive props. Its checked state can be true, false, or indeterminate according to Radix's API; inspect the installed Radix type when using advanced states.
- `Switch` wraps the `react-native-web` Switch. It maps `checked` (when provided) or `value` into the underlying `value`; it calls provided `onValueChange`, `onCheckedChange`, and `onChange` callbacks with the boolean value.
- `OptionPicker` accepts controlled `value`, `onChange(value)`, `options` (`{ value, label }[]`), optional `placeholder`, `className`, `searchable`, and `disabled`. Its source adapts the presentation to viewport width and uses a portal/modal for its picker surface. The parent still owns the selected value.
- `Label` and `Textarea` are also separately exported, with the root `Textarea` export currently coming from `input.tsx`.

<Tip>
  Controls don't own form submission or business validation. Store values and validate them in the
  parent form, and give each control a visible or programmatic label.
</Tip>
