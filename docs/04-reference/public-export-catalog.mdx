## Public types

`export *` also exposes each exported type from the modules above. Important named types include `ButtonProps`, `BadgeProps`, `InputProps`, `TextareaProps`, `SelectProps`, `BreadcrumbItem`, `BreadcrumbsProps`, `DataTableColumn`, `DataTableProps`, `CommandPaletteItem`, `CommandPaletteProps`, `TimetablePeriod`, `AddedCourse`, `GapDetail`, `SlotMap`, `TimetableGridProps`, `Timeline*Props`, `Sidebar*Props`, `SettingsSection`, `SettingsPanelProps`, `ViewModeOption`, and `ViewModeToggleProps`.

For exact types and values, inspect `src/index.ts` and the installed `.d.ts` declaration. The complete export list is generated by module re-exports, so source names can change in future releases.

## Not a root export

`src/lib/slot.tsx`'s `Slot`, `src/lib/primitives.tsx`'s `TextInput`, and source-only modules are not exported in `src/index.ts`. The package also has a special CSS import path `@amazecontinuityprojects/amazeui/tailwind.css`, declared in `package.json` exports.

`LoginForm` and `NavigationTabs` are currently root exports, but they are app-specific composites rather than general-purpose design components. Check the package repository's current release notes and source before starting new work that depends on either export.
