# AmazeUI product brief

## Product

AmazeUI (`@amazecontinuityprojects/amazeui`) is a reusable TypeScript/React
component library used by AmazeCC. The package exports controls, layout and
navigation pieces, status and progress displays, overlays, table and timetable
components, hooks, helpers, React Native Web primitives, and a CSS entrypoint.

## Audience

The handbook serves application developers integrating the npm package and
contributors changing its source. Assume HTML familiarity; explain JSX,
TypeScript props, React state/hooks, Tailwind, package entrypoints, and build
outputs.

## Success criteria

Help a new consumer install the package, load its CSS, import only supported
exports, compose components, understand caller-owned state, and diagnose type,
style, test, or package-build issues. Keep source references so contributors can
trace examples back to the implementation.
